# SWYNEX – Exploratory Data Analysis (EDA)

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) using Python on the cleaned Online Retail dataset as part of the SWYNEX Internship Task 2.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Performed

* Dataset overview
* Statistical analysis
* Missing value analysis
* Country-wise sales analysis
* Monthly sales trends
* Top-selling products
* Hourly transaction analysis
* Anomaly detection
* Business KPI calculations

## Key Findings

* 536,641 records analyzed.
* 135,037 missing CustomerID values identified.
* United Kingdom had the highest number of records.
* November 2011 recorded the highest monthly net sales.
* WORLD WAR 2 GLIDERS ASSTD DESIGNS had the highest net quantity.

## Project Structure

* data/: Cleaned dataset
* notebooks/: EDA analysis notebook

## Conclusion

The project identifies sales patterns, product performance, customer data limitations, and potential anomalies to support business decision-making.
